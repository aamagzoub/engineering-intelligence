============================================
  SUDANESE WIST - Card Game
============================================

HOW TO PLAY:

1. First time: Double-click "setup.bat"
   (installs pygame-ce, only needed once)

2. To play: Double-click "play.bat"

REQUIREMENTS:
- Windows 10/11
- Python 3.10+ (from python.org)
- Internet (first time only, for setup)

CONTROLS:
- Click cards to play
- ESC to quit (shows confirmation)
- Bidding: click number -> click suit -> confirm
